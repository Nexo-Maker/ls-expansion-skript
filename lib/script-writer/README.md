# script-writer

Builds indentation-based script files (Skript, Denizen, YAML and similar) as text, without counting
spaces by hand. It has no dependencies, so any expansion or library can use it.

```ts
import { ScriptWriter } from 'script-writer'

const w = new ScriptWriter({ indent: '    ', emptyBlock: 'stop' })
w.comment('Generated by my expansion')
w.block('on join:', (w) => {
  w.line('send "Hi" to player')
  w.block('if player is sneaking:', (w) => w.line('send "Psst" to player'))
})
w.toString()
```

| | |
| --- | --- |
| `new ScriptWriter({ indent, comment, emptyBlock })` | `indent`: one level (default four spaces). `comment`: the comment prefix (default `#`). `emptyBlock`: the line an empty block gets (Skript: `stop`; Denizen: `- define nothing true`). |
| `line(text)` | One line at the current level. A text with newlines becomes several lines. |
| `lines(texts)` | Several lines. |
| `comment(text)` | Comment lines. |
| `blank()` | A blank line, never two in a row. |
| `block(header, w => …)` | The header, then whatever the callback writes, one level in. |
| `indent(w => …)` | One level in, with no header. |
| `toString()` / `toLines()` | The file (ending with one newline), or its lines. |
| `indentLines(lines, by)` | Indents an array of already-written lines. |
